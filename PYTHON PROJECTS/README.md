# Python Projects

Small command-line projects built while practicing Python fundamentals.

| Project | Concepts practiced |
|:---|:---|
| [Mad Libs Game](madlibs_game.py) | `input()`, strings, f-strings |
| [Calculator](calculator.py) | conditionals, numeric input, arithmetic |
| [Weight Converter](weight_converter.py) | conditionals, unit conversion, rounding |
| [Temperature Converter](temperature_converter.py) | conditionals, temperature conversion, rounding |

Run any project from the repository root:

```bash
python3 "PYTHON PROJECTS/calculator.py"
```
