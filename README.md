### 📖 About

I'm Sonam, a final-year CSE student navigating placement season while building toward a specialization in **AI Engineering** — building products on top of foundation models (LLMs, RAG pipelines, agentic systems), rather than training them from scratch.

**Starting point:** Python — since AI/ML work needs a much stronger daily-driver fluency in it than competitive programming C++ ever did. Everything else (transformers, LangChain, RAG, agents) comes after this is solid.

This repo is my public log: what I'm learning, what I'm building, and the notes/projects along the way. Less "polished portfolio," more "working in the open."

> **Background:** Strong competitive programming foundation (500+ LeetCode, Knight tier, AtCoder Brown) — now channeling that problem-solving instinct into Python, ML systems, and eventually LLM tooling.
