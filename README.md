## Run locally

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r "PYTHON BASICS/requirements.txt"
```

Open `PYTHON BASICS/1.0-basic.ipynb` in VS Code or Jupyter and select the same environment as the notebook kernel.
